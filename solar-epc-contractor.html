Work covered

A solar enquiry should define whether the requirement concerns a ground-mount plant, a rooftop installation or a package within a larger project. The listed scope can include civil foundations, mounting structures, module mounting, string routes, inverter and transformer yard work, AC/DC cabling and terminations. The exact division between supply, installation, testing and client-provided material must be written into the enquiry. Bharat Infra Associates does not publish a standard capacity range on this website, so capacity, quantities and site constraints need to be reviewed for each project.
